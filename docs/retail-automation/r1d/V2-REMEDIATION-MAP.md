# R1D V2 Remediation Map

1. Maximum execution cost is reserved; actual-over-max creates a persistent violation and suspends the cost profile.
2. External outbox is attempt-scoped.
3. Explicit stale-job reconciliation.
4. `dispatching` occurs only after OS process spawn.
5. Scheduler leadership is re-proven and cleared on connection loss.
6. Certified field-map environment allowlist + reserved-variable denylist.
7. npm script must exactly match R1B certified execution command.
8. Partial unique index + adapter advisory lock prevent double-certified bindings.
9. True half-open circuit breaker with one probe token.
10. Circuit permit acquired after platform lock.
11. Attempt-scoped rate reservations can be released pre-dispatch.
12. Explicit rate policies prevent NULL-as-unlimited.
13. Versioned multi-stage cost model.
14. DAILY + MONTHLY budgets.
15. Explicit `node_js` and `tsx_file` runners.
16. Audit context bound to worker/process actor.
17. Certification hashes actual ZIP.
18. Canonical evidence text makes seal reproducible in PostgreSQL.
19. Certification/history ledgers are append-only.
20. Concurrency tests use certification-only fixtures.
21. Persistent workers claim before creating process runs.
22. External completion + outbox acknowledgement are atomic.
23. Dispatch binding requires structured non-empty QA evidence.
24. Explicit geographic transition rules.
25. `runner_policy_json` has a validated executable schema and is enforced by the worker.
