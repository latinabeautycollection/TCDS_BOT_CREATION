# ZSL1 Domain Contract

ZSL1 owns external source acquisition, release identity, raw artifact custody, source-record provenance, schema validation, ingest reconciliation, source certification and audit evidence.

ZSL1 does not own:
- canonical ZIP/ZCTA normalization,
- PostGIS hierarchy,
- retailer store-locator business logic,
- search selection,
- R1B/R1C/R1D/R1E/R1F authority,
- BUY/NO-BUY,
- capital or checkout.

Downstream readers must use only `zsl.certified_release_records`.
